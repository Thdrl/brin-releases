# brin

Signed and notarized builds of brin for Apple Silicon Macs (macOS 14+), published by Envol (Apple team 9976ZARLWT).

Download `brin-macos-arm64.zip` from the latest release, unzip it and move **brin.app** to **Applications**. brin then offers its own updates and installs one only if macOS confirms it is notarized and signed by Envol.

The other release files are incremental update packages used by the app. Do not delete old releases: newer updates refer to their files.
